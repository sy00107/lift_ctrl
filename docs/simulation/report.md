# 목표 근처 끊김 개선 — 2026-11-10

원래 작업 폴더에서 검증한 펌웨어와 UI를 이 저장소로 분리했다. 아래 수치는 원래 작업 폴더의 비교 결과다. 저장소 생성 당시 최신 감속 변경은 라파/Pico에 미적용이었으며 실물 모터를 구동하지 않았다.

## 변경

자동 목표 접근 시 기존의 `추정 속도 >= 허용 속도 → PWM 0` 조건을 연속 속도 피드백으로 바꿨다. 속도 오차에 비례해 출력 상한을 조절하고 마지막 10 mm에 감속 여유를 점진적으로 적용한다. 큰 과속·목표 도착·오류 때의 0 출력은 유지된다. 수동 조그의 기존 끝단 접근 제한은 변경하지 않았다.

UI는 Kp 0.04, Kd 0.001, PWM 상한 100%로 시작한다. 상세 설정에서 모두 편집할 수 있다. 자동 이동 요청 시 세 값을 함께 고정해 전송하며, 재실행하면 기본값으로 돌아온다. 수동 이동에도 선택한 PWM이 적용된다. 기존 보정 파일은 변경하지 않았다.

## 재현과 결과

기존 코드의 이진 속도 제한으로 끊김을 재현했다. 위치가 목표의 마지막 10 mm 구간에 있고 상태가 moving일 때 매 10 ms 출력 표본을 비교했다. 최종 도착 후 정상적인 출력 차단은 집계에서 제외했다.

|항목|변경 전|변경 후|
|---|---:|---:|
|시험 수|75|75|
|목표 도착|57|60|
|목표 부근 구동→0 출력 전환|577|0|
|목표 부근 0 출력 표본|3736|0|
|모델 물리 끝단 접촉|0|0|
|최대 모델 오버슈트|0.339 mm|0.120 mm|
|평균 시험 도착/오류까지 시간|16.29 s|14.25 s|

5개 모델 × 3개 엔코더 환산 해상도(0.1, 0.20018, 0.21574 mm/count) × 5개 상승·하강 경로를 사용했다. 경로는 10→100, 100→200, 200→100, 10→600, 600→10 mm다. Kp 0.04, Kd 0.001, PWM 상한 100%는 동일하다. 비교 결과는 탐색에 사용한 모델에서의 결과이며 독립적인 실물 검증이 아니다.

변경 후 실패 15회는 모두 미측정 고마찰(마찰 가정 22%) 모델의 무펄스 오류다. 이 조건에서도 도착한다고 주장하지 않는다. 기본 구동 보정 20%보다 높은 실제 마찰은 실측이 필요하다. 보호 감시 시간을 늘리거나 제거하지 않았다.

걸림·엔코더 유실 주입은 무펄스, 엔코더 역방향은 방향 불일치, 통신 유실은 명령 만료로 정지했다. 회귀 테스트 78개가 통과했다.

## 한계

이 시험은 최대 속도 38.1 mm/s와 가정한 마찰·관성·지연을 사용하는 소프트웨어 모델이다. 실물 이동 기록으로 실제 끊김의 원인을 확정한 것이 아니다. 단일 리프트의 하중, 최소 구동 출력, 실제 정지거리, 엔코더 누락은 식별하지 않았다. 모든 실물 조건에서 무끊김·정확도·정지를 보장하지 않는다. 목표 오차 ±0.2 mm는 엔코더 판정값이다.
